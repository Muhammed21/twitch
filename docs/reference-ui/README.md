# Référence UI : l'app iOS Twitch

**Type:** reference

Captures de l'app iOS Twitch (mars 2025, iPhone, 1179×2676), référence du design de l'app iOS du produit : structure, comportement et valeurs visuelles (ADR 0036). Les valeurs passent par les design tokens (ADR 0019) ; le périmètre est celui de l'ADR 0021. Usage : voir `.claude/rules/reference-ui.md`.

Les captures appartiennent à Twitch Interactive, Inc. et ne servent que de référence interne : elles ne sont pas redistribuées, et le logo Twitch n'est pas repris. La barre « curated by Mobbin » en bas de chaque capture ne fait pas partie de l'app.

## Nommage

`<zone>/<ecran>--<etat>.png`, en kebab-case sans accents. Le même `<ecran>` désigne le même écran d'une zone à l'autre ; `-2` distingue deux captures d'un même état. Dans chaque zone, les lignes suivent l'ordre du parcours capturé : des lignes voisines forment souvent un flux.

| Zone         | Contenu                                                     |
| ------------ | ----------------------------------------------------------- |
| `onboarding` | Écran de bienvenue, demandes de permissions                 |
| `auth`       | Inscription, connexion, codes de vérification               |
| `accueil`    | Flux vertical Following / Live / Clips                      |
| `parcourir`  | Catégories et chaînes en direct                             |
| `recherche`  | Saisie, suggestions, résultats par onglet                   |
| `chaine`     | Page de chaîne et ses onglets, follow, notifications        |
| `live`       | Lecteur, options du lecteur, blocage, signalement           |
| `chat`       | Chat de chaîne, emotes, réglages et filtres                 |
| `clips`      | Création, partage et téléchargement d'un clip               |
| `vod`        | Rediffusions                                                |
| `abonnement` | Abonnement, abonnement offert, liste des abonnements, Turbo |
| `bits`       | Cheer et achat de Bits                                      |
| `messages`   | Whispers                                                    |
| `activite`   | Onglet Activity                                             |
| `profil`     | Menu du compte, édition du profil, drops                    |
| `creer`      | Côté streamer : diffusion, Stream Manager, planning, stats  |
| `parametres` | Réglages, sécurité, apparence, préférences de contenu       |
